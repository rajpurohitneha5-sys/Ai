# AI Personal App - merged development package
This package merges the existing Android/Kotlin app and backend foundation with GitHub Actions build workflow, Apps Script gateway sample, deployment instructions, and a feature roadmap.

## Important
- Android APK focus only; iOS is out of scope.
- This is a development package, not a finished ChatGPT Pro clone or tested release APK.
- The Apps Script code is an optional gateway example and is not yet connected to the Android client. Android's current client is configured for an OpenAI-compatible gateway.
- API keys must remain server-side. Never put provider keys in the Android APK or repository.
- Use `UPLOAD_AND_TEST.md` and `google-apps-script/SETUP.md`.

See `FEATURE_SCOPE.md` for the target feature set and honest implementation status.
